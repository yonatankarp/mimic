# Security

## Supported versions

Only the latest release gets security fixes. Mimic updates itself, so the fix reaches you in the
next release.

## Reporting a problem

Please don't open a public issue for a security problem. Write to the maintainer privately
instead, using the contact details on [their GitHub profile](https://github.com/yonatankarp).

Say what the problem is, which version of Mimic has it, and how to reproduce it. Please keep it
private until a fix is released.

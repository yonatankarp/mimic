# Mimic

Turn any character into a miniature you can print, on your own Mac.

- [Mimic from a terminal](cli): every `mimic` command and option, JSON for scripts, and completing as you type.
- [How it works](https://github.com/yonatankarp/mimic#how-it-works): from a picture to a print-ready STL.
- [Working on Mimic](https://github.com/yonatankarp/mimic/blob/main/CONTRIBUTING.md): the code's layout, building, testing and releasing.
- [Get Mimic](https://github.com/yonatankarp/mimic/releases/latest)

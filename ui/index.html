Mimic

Turn any character into a miniature you can print

🧙 One-time setup

Pictures work right away. To use ✍️ Describe it or the grey-sculpt step, Mimic needs the free Draw Things app.

⬜
Open Draw Things.
⬜
Turn on its connection.
In Draw Things: Settings → Advanced → API Server. Turn it on, choose HTTP, set the port to 7860.
⬜
Download FLUX.2 Klein.
In Draw Things' model list, search for FLUX.2 Klein and download it. It's big, so give it a few minutes.

This list updates on its own. You can keep going meanwhile.
